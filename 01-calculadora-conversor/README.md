# Día 1: Calculadora y Conversor de Unidades (CLI)

Primer proyecto práctico en mi camino de aprendizaje de Python desde cero.

## 🎯 Objetivos de aprendizaje
- Comprender la función `print()` y `input()`.
- Trabajar con tipos de datos numéricos (`int`, `float`) y cadenas de texto (`str`).
- Aplicar control de flujo con `if`, `elif` y `else`.
- Crear funciones modulares (`def`).
- Manejar errores comunes como división por cero y entradas no numéricas (`try/except`).

## 🚀 Cómo ejecutar
```bash
python calculadora.py
```

## 📋 Funcionalidades
- Operaciones aritméticas básicas (Suma, Resta, Multiplicación, División).
- Conversión de temperatura: Celsius a Fahrenheit.
- Conversión de distancia: Kilómetros a Millas.
- Menú interactivo continuo en consola.
